## 📌 Project Overview
Multi-container fintech platform for recurring billings, automated wallet debits, BullMQ transaction job queues, and webhook event management.

---

## ⚙️ Technical Specifications & Details
### System Architecture:
- Next.js 16 + React 19 frontend client.
- Express API with rate limiting, Zod validation, JWT authentication.
- PostgreSQL 16 relational database with migration scripts.
- Redis 7 + BullMQ asynchronous scheduled payment queues.
- Docker Compose orchestration with automated healthchecks.
